# Демо настройки фона и цвета

Интерактивное демо по макету Figma. HTML, CSS и JavaScript; установка зависимостей и сборка не нужны. Все изображения, иконки, шрифты и видео находятся в `assets/`.

## Запуск

Откройте `index.html` в настольном браузере. Для локального HTTP-просмотра можно выполнить в папке проекта:

```sh
python -m http.server 8000
```

Затем откройте `http://localhost:8000/`.

Размер области редактора — 1024×768 px; справа расположена системная панель шириной 352 px. Полная ширина демо — 1376 px. Мобильная версия не предусмотрена.

## Что работает

- «Фон»: палитра, HEX, прозрачность, ручной выбор цвета, системная пипетка, градиенты, текстуры и размытие.
- «Медиа»: выбор предоставленных фото и видео через псевдопроводник, кадрирование фото, режимы отображения, расположение и стили.
- Настройки фото: прозрачность, размытие, контраст, насыщенность и температура. У видео доступны прозрачность, размытие, затемнение и осветление.
- Воспроизведение видео в маленьком превью. Применённое видео воспроизводится на повторе без звука.
- Просмотр фото и видео в большом окне; там элементы управления декоративные, работает закрытие.
- Общее окно «Цвет» для картинки, точек градиента и самостоятельных сценариев выбора цвета.
- Общие «Мои» и история, закрепление, открепление, изменение порядка и подсказки.
- Системная панель: демонстрационные состояния «Фона», состояния «Цвета» и статичный экран «Вызывающий элемент».

## Поведение

Галка применяет выбор и закрывает окно. Крестик отменяет локальные изменения, сброс возвращает значение на момент открытия. Клик по кружку палитры подтверждает выбор сразу.

Вложенное окно «Цвет» передаёт значение в родительское окно и записывает его в общую историю. Фон меняется после подтверждения родительского окна «Фон».

Пользовательские данные хранятся только до обновления страницы. Системная панель временно скрывает коллекции для первого входа и подставляет примеры из макета при отсутствии пользовательских данных. В окнах «Цвет» из коллекций исключаются градиенты, текстуры и ненулевое размытие.

«С элементом Без цвета» — отдельное состояние раздела «Цвет». Значения «Основной» и «Другой» редактируются независимо; блок «Где используется» декоративный.

Размытие: видимое значение 0–5, фактический CSS blur — значение ÷ 2 px. Контраст и насыщенность: 0–200%, температура: −50…+50.

Пипетка использует браузерный `EyeDropper API` и доступна в поддерживающих его браузерах, например Chrome и Edge.

## Публикация на GitHub Pages

Содержимое этой папки должно находиться в корне репозитория: рядом с `index.html` должны лежать скрипты, CSS, `.nojekyll` и папка `assets/`.

В настройках репозитория откройте **Settings → Pages**:

1. **Source** — **Deploy from a branch**.
2. Ветка — `main`, папка — **/ (root)**.
3. Нажмите **Save** и дождитесь завершения публикации.

После публикации GitHub покажет адрес демо в разделе Pages. Папка `work/` из рабочей среды не нужна для размещения сайта.

[Инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
